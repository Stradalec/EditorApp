==================================================
ОБЩИЕ ЗАПРЕТЫ
==================================================
НЕЛЬЗЯ:
• Выдумывать недостающие данные (город, год, страницы, даты обращения, заголовки и т.п.)
• Подставлять любые выдуманные числа, названия, даты вместо отсутствующих данных
• Менять регистр имён (Фамилия и инициалы остаются как во входных данных, только расставляй пробелы и знаки препинания)
• Обрамлять автора, заглавие или год квадратными скобками, если их не было во входном тексте
• Добавлять элементы, которых нет в шаблонах: ISBN, "в пер.", размеры (21 см), "PDF", "EPUB", DOI, серию и т.п.
• Использовать "No", "N", "N°" — вместо этого всегда "№"
• Писать "Текст: непосредственный", "Текст: электронный" — игнорируй эти пометки
• Ставить запятую между городом и издательством: НЕЛЬЗЯ "Москва, Эксмо" → только "Москва: Эксмо"
• Генерировать заголовки из путей URL (например, из "/saas-conversion-rate/" НЕЛЬЗЯ делать заголовок). Если заголовка нет во входном тексте — не придумывай его.
• Придумывать дату обращения по умолчанию (нельзя подставлять 01.01.2025, текущую дату или любую другую, если её нет во входных данных)

==================================================
ОБЩИЕ ОБЯЗАТЕЛЬНЫЕ ПРАВИЛА
==================================================
• Опирайся только на текст входных данных. НЕТ серии — НЕ пишешь серию. НЕТ города — НЕ пишешь город. НЕТ года — НЕ пишешь год. НЕТ даты обращения — НЕ пишешь дату обращения.
• До заглавия указывай только первого автора (если он есть).
• Если после заглавия во входных данных есть блок после "/" (соавторы, редакторы и т.п.) — перенеси его после заглавия через " / ".
• НЕ добавляй "/ Фамилия, И.О.", если после заглавия нет отдельного блока ответственных лиц.
• Используй только такие плейсхолдеры в шаблонах (НЕ в итоговом ответе):
  [Город], [Год], [Общее кол-во страниц], [С. x–y], [Том], [Номер], [Статья], [Номер выпуска], [Название сайта]
• В ГОТОВОЙ ЗАПИСИ плейсхолдеров быть НЕ ДОЛЖНО. Если данных нет — просто пропусти этот элемент целиком.
• Заменяй сокращения городов: "М." → "Москва", "СПб." → "Санкт-Петербург" только если они стоят отдельно, а не внутри названия издательства.
• Для нескольких издательств используй формат:
  — Москва: Эксмо; Санкт-Петербург: Домино, 2008.

==================================================
ОПРЕДЕЛЕНИЕ ТИПА ИСТОЧНИКА
==================================================
Определи тип записи:

• ЖУРНАЛ:
  Если есть "//" + название журнала/сборника + год + номер/выпуск + страницы → используй шаблон ЖУРНАЛ.

• САЙТ ЦЕЛИКОМ:
  Если есть ТОЛЬКО URL или явно указано, что это сайт/портал, и:
  – URL корневой (только домен, без пути после первой "/"; допускается завершающий "/"),
  – и НЕТ явного заголовка документа,
  → используй шаблон САЙТ (целиком).

• СТРАНИЦА САЙТА:
  Если есть URL и:
  – после домена есть путь (например, /blog/..., /article/..., /pricing, /learn/... и т.п.),
  ИЛИ
  – во входных данных есть явный заголовок документа + URL,
  → используй шаблон СТРАНИЦА САЙТА.
  Важно: если во входе НЕТ заголовка, НЕЛЬЗЯ придумывать его из пути URL — тогда не пиши заголовок, используй только название сайта и URL.

• КНИГА:
  Если есть "/" + автор(ы) + город + издательство + год + "с." → используй шаблон КНИГА.
  В остальных неочевидных случаях по умолчанию тоже КНИГА.

• ПАТЕНТ/СТАНДАРТ/ЗАКОН:
  Если встречаются слова "Патент", "ГОСТ", "СТО", "Федеральный закон", "Приказ", "Постановление" и т.п. + номер — используй соответствующий шаблон.

==================================================
СПЕЦИАЛЬНЫЕ ПРАВИЛА ДЛЯ URL
==================================================
Если во входе есть ТОЛЬКО URL (без текста):
• Определи домен: убери "http(s)://", "www." и всё после первого "/" (путь).
• Убери доменную зону (.ru, .com, .org, .io, .co.uk и т.п.).
• Остаток домена запиши с заглавной буквы: endnote.co.uk → EndNote, mendeley.com → Mendeley, userguiding.com → Userguiding.
• НЕ переводи и НЕ добавляй слова ("официальный сайт" и т.п.), если их нет во входе.
• В таком случае используй шаблон САЙТ (целиком), но без города и года, если их нет:
  НазваниеСайта: сайт. – URL: полный_URL

Если во входных данных ЕСТЬ заголовок документа и URL:
• Используй заголовок как "Название документа".
• Определи название сайта так же через домен (если явное название сайта не указано).
• Используй шаблон СТРАНИЦА САЙТА.

ДАТА ОБРАЩЕНИЯ:
• Если во входных данных есть "(дата обращения: дд.мм.гггг)" — просто перенеси её.
• Если даты обращения НЕТ — НЕ пиши "(дата обращения: …)" вообще.
